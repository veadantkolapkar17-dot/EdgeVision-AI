ACADEMIC OVERVIEW

About EdgeVision AI

Edge AI-based Real-time Object Detection for Smart Media Applications.

Project Specifications

EdgeVision AI is a 2nd-year B.Tech computer science and engineering project demonstrating the viability of on-device neural network execution. By compiling YOLO11n into an optimized ONNX computational graph and executing it directly inside the browser using WebGPU and WebAssembly SIMD, real-time object detection is achieved without cloud servers.

Core Technology Stack
HTML5 / Modern DOM CSS3 (Grid & Flexbox) JavaScript (ES6 Modules) Ultralytics YOLO11n ONNX Runtime Web 1.21.0 WebGPU API WebAssembly (WASM SIMD) WebRTC MediaStream
